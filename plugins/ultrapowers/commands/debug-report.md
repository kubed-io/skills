This bug is yours to assess. If this session has not read it yet, read `skill://superpowers/systematic-debugging/SKILL.md` first, and follow it up to its implementation phase, not into it: the fix goes in your report, not into the code.

Find what happens and why: read the issue and the code it touches, then the live system the code runs as, and trust what you can see over what the issue assumes. Report in your notes what happens, where, the evidence, the likely cause and a proposed fix, and what is still open. Change nothing.
